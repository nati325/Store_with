# חנות לעסקים (bulk-shop)

חנות אינטרנטית למכירת מתנות, מוצרי מותג וציוד לאירועים לחברות, בכמויות.
Next.js 14 (App Router) + Prisma + PostgreSQL. עברית RTL, שקלים, מע״מ 18%.

## מה יש
**לקוחות**
- קטלוג עם חיפוש, מיון וסינון לפי קטגוריה
- עמוד מוצר: טבלת מחירי כמות שמדגישה את המדרגה הפעילה, כמות מינימום, וחישוב מיידי
- עגלה (נשמרת בדפדפן). המחירים מחושבים בשרת בלבד
- הזמנה ללא תשלום באתר: פרטי חברה, ח.פ., כתובת, מועד אירוע והערות
- דף מעקב להזמנה עם סטטוס, וכפתור "לתשלום" כשהוגדר קישור תשלום
- בקשת הצעת מחיר לכמויות חריגות או התאמה אישית
- עמודי תקנון, פרטיות והצהרת נגישות (תבניות, ראו "לפני עלייה לאוויר")
- מצב כהה, מובייל, SEO (sitemap, robots, כותרות)

**ניהול (`/admin`, סיסמה ב-`ADMIN_PASSWORD`)**
- סקירה: הזמנות חדשות, הכנסות, שווי פתוח, בקשות הצעת מחיר
- הזמנות: חיפוש וסינון, עמוד פרטים, עדכון סטטוס, קישור תשלום, הערות פנימיות, אימייל ללקוח
- אישור הזמנה להדפסה או PDF (אינו חשבונית מס), וייצוא כל ההזמנות ל-CSV
- הצעות מחיר: רשימה וסימון כטופלה
- מוצרים: יצירה, עריכה, מדרגות מחיר, העלאת תמונה, השבתה ומחיקה

**אבטחה**: מחיר מחושב בשרת, הגבלת קצב להזמנות/הצעות/כניסת מנהל, שדה פיתיון נגד בוטים, העלאות עם בדיקת סוג ותוכן, קישור תשלום רק https, הגנה מהזרקת נוסחאות ב-CSV.

## הרצה מקומית
```bash
cp .env.example .env
docker compose up -d          # Postgres
npm install
npm run db:push               # יצירת טבלאות
npm run db:seed               # מוצרי דוגמה
npm run dev
```
חנות: http://localhost:3000 · ניהול: http://localhost:3000/admin

## הגדרות (`.env`)
| משתנה | תיאור |
|---|---|
| `DATABASE_URL` | חיבור ל-Postgres |
| `ADMIN_PASSWORD` | סיסמת הניהול. חובה להחליף |
| `SITE_URL` | כתובת האתר, לקישורים באימיילים וב-SEO |
| `SMTP_URL`, `MAIL_FROM`, `ADMIN_EMAIL` | אימייל. בלי `SMTP_URL` ההודעות נרשמות ללוג בלבד |
| `UPLOAD_DIR` | תיקיית תמונות. חייבת להיות על אחסון קבוע |

## תשלום
האתר לא סולק אשראי בעצמו. בכל הזמנה מדביקים בניהול קישור תשלום (https) מהסולק שבו אתם משתמשים (Cardcom, Tranzila, PayPlus, Stripe וכו׳), והלקוח רואה כפתור "לתשלום" בדף ההזמנה ובאימייל. אחרי התשלום מסמנים "שולמה". שילוב סליקה אוטומטי עם webhook אפשרי כהרחבה.

## פריסה
`Dockerfile` מצורף: מבנה, מסנכרן סכמה בעלייה ומרים את האתר. צריך Postgres, ואחסון קבוע ל-`UPLOAD_DIR`. הגבלת הקצב נשמרת בזיכרון, ולכן מתאימה למופע שרת אחד.
ה-Dockerfile לא נבדק בסביבת הפיתוח (לא היה Docker זמין).

## לפני עלייה לאוויר
- להחליף `ADMIN_PASSWORD`, ולהגדיר `SITE_URL` ו-SMTP
- להשלים ולבדוק משפטית את `/terms`, `/privacy`, `/accessibility` (מסומנות כתבניות עם שדות [להשלמה])
- להפיק חשבוניות מס במערכת הנהלת חשבונות. האתר מפיק רק אישור הזמנה

## בדיקות
`npm test` בודק חישובי מחיר ומע״מ, מדרגות, CSV, הגבלת קצב ואימות קישורי תשלום.

# bulk-shop

חנות אינטרנטית למכירת מתנות ומוצרי מותג לחברות ולאירועים בכמויות.
Next.js 14 (App Router) + Prisma + PostgreSQL. עברית RTL, שקלים, מע״מ 18%.

## מה יש בגרסה הראשונה (MVP)
- קטלוג מוצרים וקטגוריות, עמוד מוצר עם טבלת מחירי כמות
- מחיר יחידה יורד לפי כמות, וכמות מינימום להזמנה לכל מוצר
- עגלה (נשמרת בדפדפן). המחירים מחושבים בשרת בלבד
- הזמנה ללא תשלום אונליין: פרטי חברה, כתובת, מועד אירוע והערות
- ניהול בסיסי ב-`/admin`: צפייה בהזמנות ועדכון סטטוס, הוספת מוצרים והשבתתם

לא כלול עדיין: סליקת אשראי, הפקת חשבוניות, שליחת אימיילים, העלאת תמונות.

## הרצה מקומית
```bash
cp .env.example .env
docker compose up -d          # Postgres
npm install
npm run db:push               # יצירת טבלאות
npm run db:seed               # מוצרי דוגמה
npm run dev
```
החנות: http://localhost:3000 · ניהול: http://localhost:3000/admin (הסיסמה ב-`ADMIN_PASSWORD`).

## בדיקות
`npm test` בודק את חישובי המחיר והמע״מ.

## מבנה
- `prisma/schema.prisma` מודל הנתונים (מחירים באגורות)
- `src/lib/pricing.ts` מדרגות מחיר ומע״מ
- `src/lib/orders.ts` חישוב עגלה בשרת
- `src/app/` דפי החנות, ה-API והניהול
